# maps

TrenchBroom maps and everything the editor and compiler need. This folder is the game root: TrenchBroom's game path and qbsp's `-basedir` both point here.

- `*.map`: maps in Quake 2 (Valve) format. The `.map` file is the source of truth.
- `textures/<folder>/<name>.png`: textures, referenced by name (`<folder>/<name>`) from maps. `textures/dev/` holds placeholder grid and solid-color textures generated by `tools/make_placeholder_textures.py`.
- `trenchbroom/`: the Hollow Coil game config and FGD. Run `python tools/install_trenchbroom.py` to link it into TrenchBroom, then set the Hollow Coil game path to this folder in TrenchBroom's preferences.

New maps must start with `// Game: Hollow Coil` (TrenchBroom writes this when you create a map with the Hollow Coil game).

Compiled `.bsp` files go to `/build`, never here.
